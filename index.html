Computing System：零件怎麼一起完成工作？

先分清硬體與軟體，再用六層架構看它們如何合作。

講義把 computing system 定義成一個 dynamic entity（動態實體）：它接收環境中的資訊、處理問題，並與環境互動。例如你按下鍵盤，系統處理輸入，畫面顯示文字；這一連串行為就是系統正在運作。

Hardware · 實體元件

電腦「用什麼」執行工作

Hardware 是實體元件。講義例子有 printer（印表機）、circuit boards（電路板）、wires（線路）、keyboard（鍵盤）。它們能接收、傳送或處理實際的訊號。

辨認方法：看這個名詞指的是設備或元件，還是提供指令的程式。

Software · 程式與指令

電腦「按照什麼規則」工作

Software 是提供 instructions（指令）的 programs（程式）。例如「把輸入的文字顯示出來」這個行為，需要軟體告訴硬體要怎麼做。

理解用例：手機的螢幕是硬體；執行中的聊天程式是軟體。作業系統也是軟體。

兩者的關係：軟體提供做事的規則，硬體執行這些規則。辨認時看名詞的角色：下載的程式屬於軟體，承載它的儲存設備屬於硬體。

六層架構：點一層，看它負責什麼

講義第 5 頁的圖，由內到外是 Information → Hardware → Programming → Operating systems → Applications → Communications。最內層關心資訊，外側逐步加入操作資訊的設備、程式、管理、應用與通訊。

歷史：從記錄數值，到描述計算步驟

把每個人物連到一項貢獻，再理解這項貢獻讓什麼變得可能。

這段歷史可以沿著一條線理解：記錄數值 → 機械運算 → 用編碼控制動作 → 設計計算機 → 撰寫計算步驟 → 研究計算的理論。這樣遇到人物配對題，就能從他的工作找答案。

Abacus（算盤）→ 記錄數值講義將算盤列為早期記錄 numeric values 的裝置。重點是用可操作的形式表示數值。
Blaise Pascal → 機械式加減早期機械裝置能做 addition、subtraction；講義接著指出後來的裝置擴展到乘法與除法。看到 Pascal，要想到 mechanical calculation。
Joseph Jacquard → 織布機與 Punched card打孔卡用來控制織布機。理解重點：把要做的動作編成可讀取的形式，機器就能照編碼操作。
Charles Babbage → Analytical Engine（分析引擎）講義將分析引擎與 Babbage 配對。記住他主要對應的是計算機的設計。
Ada Lovelace → First programmer／Loop講義稱她為第一位程式設計師，並列出迴圈概念。Loop 是讓相同的一組步驟重複執行，重點在描述「怎麼算」。
Alan Turing → Turing machine（圖靈機）講義強調圖靈機奠定計算理論的重要基礎。看到 Turing，要想到對計算本身的理論研究。

容易混淆：Babbage vs Ada

Babbage＝機器設計；Ada＝程式與迴圈。兩人都與分析引擎的脈絡有關，但配對時要看題目在問機器，還是程式設計。

早期電腦名稱

Harvard Mark I、ENIAC、UNIVAC I 都是講義列出的早期電腦。講義指出它們開啟數學、物理、工程與經濟等領域的新應用。

Fortran／COBOL／Lisp 是語言；Mosaic／Netscape 是瀏覽器。先判斷名稱是哪一類，選項就容易排除。

配對口訣：算盤＝數值；Pascal＝加減；Jacquard＝打孔卡；Babbage＝分析引擎；Ada＝程式／迴圈；Turing＝圖靈機。

Sequential vs Direct access

Sequential（循序）像從前面依序讀資料；Direct（直接）能定位要取出的資料。講義用磁帶與磁碟來比較兩者。

理解用例

像要找第六筆紀錄：循序方式一路讀過前面的紀錄；直接方式可指定要找的紀錄。這個比喻用來理解「存取方式」。

CISC vs RISC

CISC＝Complex-instruction-set computer（複雜指令集）。RISC＝Reduced-instruction-set computer（精簡指令集）。

先抓 Complex／Reduced 這兩個英文詞。它們是在分指令集設計；看到名詞，先回答它代表哪種設計。

Portable computer 的講義例子有 notebook、laptop、tablet computer、smart phone。

Parallel Computing：分工的是指令，還是資料？

把縮寫拆成 Instruction 與 Data，再看實際的分工。

講義的平行計算是利用相互連接的處理單元或記憶單元增加處理速度。理解 SIMD／MIMD 時，先問兩件事：「大家收到同一種指令嗎？」以及「大家處理的是多份資料嗎？」

SIMD

Single Instruction, Multiple Data Stream

SI＝單一指令；MD＝多筆資料。多個處理單元使用相同指令，分別作用在不同資料上。

理解用例

四個人分別拿到 2、4、6、8；所有人都接到「加 1」的指令。工作相同，資料不同。

MIMD

Multiple Instruction, Multiple Data Stream

MI＝多種指令；MD＝多筆資料。不同處理單元可以執行不同指令，處理不同資料。

理解用例

四個人分別接到「加 1、乘 2、減 1、平方」的工作；各自處理自己的資料。

縮寫讀法：先看前半段 SI／MI，決定指令是同一種還是多種。兩者的 MD 都表示 Multiple Data；差異就在 Instruction。

    進位轉換：三個方法

    不同方向用不同方法，會比硬背所有表格簡單很多。

    To Decimal

    其他進位 → 10 進位

    使用位置權重：每位數 × base 的次方後相加。

    From Decimal

    10 進位 → 其他進位

    整數常用「反覆除以 base，記錄餘數，再由下往上讀」。

    Shortcut

    2 ↔ 8 / 16

    Octal 每 1 位對應 3 bits；Hex 每 1 位對應 4 bits。

    考試怎麼算：先判斷是哪一種題型

    先記這三句： 看到「→ Decimal」就乘次方； 看到「Decimal →」就一直除、餘數倒著讀； 看到 Binary ↔ Octal / Hex，就直接每 3 bits / 4 bits 分組。
    Type 1 · To Decimal

    ① 其他進位 → 10 進位：乘權重再相加

    例：(30B)₁₆ → (?)₁₀

    16 進位中 A=10、B=11、C=12、D=13、E=14、F=15。

    從最右邊開始，位數權重依序是 16⁰、16¹、16²⋯。

    (30B)₁₆ = 3×16² + 0×16¹ + 11×16⁰
    = 3×256 + 0 + 11 = 779

    答案： (30B)₁₆ = (779)₁₀

    其實和十進位 352 = 3×10² + 5×10¹ + 2×10⁰ 是同一個概念，只是把 base 換成 16。

    Type 2 · From Decimal

    ② 10 進位 → 其他進位：一直除，餘數倒著讀

    例：(2748)₁₀ → (?)₁₆

    計算商餘數
    2748 ÷ 1617112 = C
    171 ÷ 161011 = B
    10 ÷ 16010 = A

    餘數一定要由下往上讀：A → B → C。

    (2748)₁₀ = (ABC)₁₆

    最常錯：把餘數由上往下讀成 CBA。

    Type 3 · Binary Shortcut

    ③ Binary ↔ Octal / Hex：直接分組

    因為 8 = 2³，所以 Binary ↔ Octal 每 3 bits 一組；16 = 2⁴，所以 Binary ↔ Hex 每 4 bits 一組。

    Binary → Hex

    例：(10010110)₂

    1001  0110 → 9  6

    所以 (10010110)₂ = (96)₁₆。

    Binary → Octal

    從右邊每 3 bits 分組，不足時在左邊補 0。

    10010110 → 010  010  110 → 2  2  6

    所以 (10010110)₂ = (226)₈。

    反過來 Octal / Hex → Binary： 每一個 Octal digit 各換成 3 bits；每一個 Hex digit 各換成 4 bits，再把各組接起來。 例如 (226)₈ → 010 010 110 → (10010110)₂；最左邊不影響數值的 0 可以省略。
    同一個值的完整對照： (150)₁₀ = (10010110)₂ = (226)₈ = (96)₁₆。 考試時先看「從哪一進位轉去哪一進位」，再選方法，不要全部都用同一套算法。

    (2748)₁₀ → Hex

    (2748)₁₀ = (ABC)₁₆

    同一個值的不同表示

    (150)₁₀ = (10010110)₂ = (226)₈ = (96)₁₆
    超重要： Binary ↔ Octal：每 3 bits 分一組。Binary ↔ Hex：每 4 bits 分一組。

    Binary Arithmetic

    二進位加法規則少，但進位的位置很容易粗心。

    運算結果說明
    0 + 00不進位
    0 + 1 / 1 + 01不進位
    1 + 110₂寫 0，進 1
    1 + 1 + 111₂寫 1，進 1

    教材例題：二進位直式相加

    和十進位直式加法一樣，從最右邊開始，只是二進位逢 2 就進位。

    1010111 + 1001011 --------- 10100010

    第一步：最右邊 1 + 1 = 10₂，所以這一欄寫 0，往左進 1。

    第二步：下一欄要把進位一起加：1 + 1 + 1 = 11₂，所以寫 1，再進 1。

    後面每一欄都照同樣規則往左算，最後得到 (10100010)₂。

    考試做法：從右往左一欄一欄加；遇到 1 + 1 就「寫 0 進 1」，遇到 1 + 1 + 1 就「寫 1 進 1」。建議把進位標在上一列，比較不容易漏掉。

    Binary Subtraction（二進位減法）

    先懂「借 1」是什麼： 十進位向左借 1，這一欄會多 10；二進位向左借 1，這一欄會多 2，也就是 10₂。 所以遇到 0 − 1 時，可以變成 10₂ − 1₂ = 1₂。
    Step 1 · Rules

    先記 4 個基本情況

    運算結果要不要借位
    0 − 00不用
    1 − 01不用
    1 − 10不用
    0 − 11要：先變成 10₂ − 1₂
    Step 2 · Simple Borrow

    最簡單借位：10₂ − 1₂

    10 - 01 ---- 01

    最右邊是 0 − 1，不夠減，所以向左邊的 1 借 1。

    左邊的 1 變成 0；右邊的 0 得到 10₂，所以 10₂ − 1₂ = 1₂。

    連續借位：中間遇到 0 怎麼辦？

    例如 1000₂ − 0001₂。最右邊 0 − 1 不夠，但左邊緊鄰的兩欄也都是 0，所以要一路往左找到第一個 1。

    1000 - 0001 ------ 0111

    最左邊的 1 借出去後變 0；借位一路傳過兩個 0，最後右邊三欄都能完成減法，所以 (1000)₂ − (1)₂ = (111)₂。

    教材例題：逐欄看 borrow

    1010111 - 0111011 --------- 0011100

    從最右邊開始：

    1. 第 1 欄：1 − 1 = 0。
    2. 第 2 欄：1 − 1 = 0。
    3. 第 3 欄：1 − 0 = 1。
    4. 第 4 欄：0 − 1 不夠，向左借 1 → 10₂ − 1₂ = 1。
    5. 第 5 欄：因為剛剛被借走，這欄變成 0；現在又是 0 − 1，所以要再向左借。
    6. 左邊下一欄也是 0，因此借位要再往左找到 1，再把 borrow 傳回來。
    7. 剩下各欄完成相減後，結果是 0011100₂。
    考試口訣：從右往左減；夠減就直接減，不夠減就向左借 1。如果左邊是 0，就繼續往左找到第一個 1。Addition 看 carry；Subtraction 看 borrow。

    二、八、十六進位：相加與相減

    先看基底，再從最右欄算。一步一步處理進位與借位。

    不用每次先轉成二進位。同一種進位的兩個數，可以直接直式加減。你熟悉的十進位是「滿 10 進 1、借 1 補 10」；現在只要把 10 換成題目的基底。

    這張表裡的 2、8、16 都表示十進位的數量。
    進位可用的數字加法何時進位減法借 1 得到多少
    二進位（base 2）0、1滿 2：1＋1＝10₂本欄多 2，也就是 10₂
    八進位（base 8）0～7滿 8：7＋1＝10₈本欄多 8，也就是 10₈
    十六進位（base 16）0～9、A～F滿 16：F＋1＝10₁₆本欄多 16，也就是 10₁₆
    為什麼借位要補基底？左邊一欄的位權，是目前欄的 b 倍。所以左欄少 1，就能讓本欄多 b，總數值不變。八進位借 1 補 8；十六進位借 1 補 16。
    Addition · 加法

    本欄兩個數字，加上右欄的進位

    從右往左算。總和若小於基底，就直接寫下；總和若達到基底，就減掉一個基底，留下的數寫在本欄，再往左進 1。

    例如八進位：7＋6＝13（十進位），13＝1×8＋5，所以本欄寫 5、往左進 1。最後最左邊還有進位，也要寫出來。

    Subtraction · 減法

    先扣掉被右欄借走的 1，再看夠不夠減

    從右往左算。不夠減就向左借 1，本欄補上基底；左欄下次計算時要記得少 1。

    十六進位 A−B：A＝10、B＝11，不夠減。借位後 10＋16−11＝15＝F，所以本欄寫 F，左欄少 1。

    八進位加法：57₈＋26₈＝105₈

    57 + 26 ---- 105
    1. 個位：7＋6＝13（十進位）。13÷8＝1 餘 5 → 寫 5、進 1。
    2. 八位：5＋2＋剛才進的 1＝8 → 寫 0、再進 1。
    3. 最左邊寫出最後的 1 → 答案 105₈。

    最常漏的是第二欄的「＋1」。核對：57₈＝47₁₀、26₈＝22₁₀，47＋22＝69₁₀＝105₈。

    十六進位減法：4A₁₆−1B₁₆＝2F₁₆

    A＝10、B＝11、C＝12、D＝13、E＝14、F＝15。

    4A - 1B ---- 2F
    1. 個位：A−B＝10−11，不夠。向左的 4 借 1，4 變成 3；本欄增加 16。
    2. 個位變成 10＋16−11＝15 → 寫 F。
    3. 十六位：借出去後是 3−1＝2 → 答案 2F₁₆。

    記住：借 1 是補 16，所以不能照十進位的習慣只補 10。

    連續借位：左邊也是 0，怎麼辦？

    以 1000₈−0001₈ 為例，往左找到第一個不是 0 的數字。最左邊的 1 變成 0；中間的 0 接到 8，又把 1 借給右邊，於是剩下 7；最右欄得到 8 再減 1，也是 7。

    1000₂−1₂＝111₂
    1000₈−1₈＝777₈
    1000₁₆−1₁₆＝FFF₁₆

    中間被借位經過的 0，會留下「基底−1」：二進位是 1、八進位是 7、十六進位是 F。

    考前避免三個錯誤：先把個位對齊；右欄的進位或借位不能漏；答案每一位都必須是該基底允許的數字（八進位不能寫 8 或 9）。兩個數若是不同進位，先轉成同一種再算。左邊補 0 只是對齊，不改變數值。

    資料與數位化：把連續世界變成可表示的數值

    所有資料最後都以 bits 儲存；解讀方式由表示規則決定。

    電腦處理 Numbers、Text、Audio、Images／Graphics、Video。它們的內容不同，但儲存時都用 binary digits（bits）。例如同樣的 01000001，當成無號整數是 65；以 ASCII 解讀則是字母 A。

    ANALOG · 類比

    Continuous：連續變動

    類比資料以連續方式表示，例如水銀溫度計的液柱、聲波或持續改變的電壓。相鄰數值之間還能有更多細小變化。

    DIGITAL · 數位

    Discrete：離散的元素

    數位資料分成獨立元素，用有限的數值表示。數位電子訊號以高／低兩個狀態對應 1／0。

    Digitize 與 Degradation

    Digitize（數位化）是將類比資料分成部分，再分別表示；聲音的取樣與量化就是後面的實例。類比和數位訊號都會受到環境干擾而劣化（Degradation）。講義指出數位訊號可定期重新定時（reclock）恢復波形；辨認高低狀態仍有條件，不能推成「數位訊號永遠不會出錯」。

    n 個 bits，為什麼有 2ⁿ 種組合？

    每一位有 0、1 兩種選擇。2 bits：2 × 2＝4 種；3 bits：2 × 2 × 2＝8 種。8 bits 有 256 種組合；若表示無號整數，範圍是 0–255。「種類數」和「最大數值」差 1，因為包含 0。

    Compression：為何要壓縮？

    儲存空間和傳輸頻寬有限，所以希望用較少資料表示內容。Lossless（無失真）能還原原始資料；Lossy（失真）會捨棄部分原始資訊。

    負數：固定的 bits，要用什麼規則解讀？

    先固定寬度，再表示負數；同一個位元圖樣可以有不同意思。

    ① Signed-magnitude：符號與數量分開

    帶號–數量表示法用最左位表示正負（0 正、1 負），其餘位表示絕對值。8-bit 的 +2 是 00000010，−2 是 10000010。

    問題：有兩個零。00000000 是 +0，10000000 是 −0。8-bit 帶號–數量的範圍是 −127 到 +127；下面的二補數則只有一個 0。

    ② 先用兩位十進位，理解 Ten’s Complement（10 補數）

    講義將 00–49 解讀為 0–49，50–99 解讀為 −50–−1。因此 97 表示 −3。位數要固定：兩位數用 10²−3＝97；三位數用 10³−3＝997。

    原本算式固定兩位數的計算解讀
    5＋(−6)05＋94＝9999 表示 −1
    −4＋696＋06＝102 → 保留 022；丟掉超出兩位的百位
    −2＋(−4)98＋96＝194 → 保留 94−6
    −5−395＋97＝192 → 保留 92−8；把減法改成加負數

    為什麼可丟掉百位？我們只保留固定兩位，相當於保留除以 100 的餘數；100 在這套表示法中回到 00。前提是最後的正負數結果仍在可表示範圍內。

    ③ Two’s Complement（2 補數）：反轉，再加 1

    用 k bits 表示 −I（I > 0）時，其位元圖樣對應無號值 2ᵏ−I。8-bit 的 −2：256−2＝254＝11111110。計算捷徑如下：

    +2：00000010 → 反轉：11111101 → 加 1：11111110 → 解讀為 −2

    為什麼反轉再加 1？k bits 全部是 1 的值為 2ᵏ−1。反轉 I 得到 (2ᵏ−1)−I，再加 1，剛好是 2ᵏ−I。這是在固定寬度內計算，不是在左邊寫一個負號。

    小數換算：整數一直除，小數一直乘

    小數點右邊的位權是負次方；浮點數再用指數調整尺度。

    二進位 radix point（基數點）右邊的位權依序是 2⁻¹＝1/2、2⁻²＝1/4、2⁻³＝1/8……。因此 0.11₂＝1/2＋1/4＝0.75₁₀；10.101₂＝2＋1/2＋1/8＝2.625₁₀。

    十進位小數 → 二進位：乘 2，取整數，留下小數

    1. 將「目前的小數部分」乘 2。
    2. 記下結果的整數部分（0 或 1），這是下一個 bit。
    3. 留下結果的小數部分，再乘 2；直到小數為 0 或到指定精度。
    4. bits 按取得順序由上往下讀，放在基數點後面。
    0.75 的步驟取出 bit留下的小數
    0.75 × 2＝1.5010.50
    0.50 × 2＝1.0010；結束
    0.75₁₀＝0.11₂；核對：1 × 2⁻¹＋1 × 2⁻²＝0.75
    不要混用讀法：整數部分「除 2，餘數由下往上讀」；小數部分「乘 2，整數位由上往下讀」。例如 5.75：5→101；0.75→.11；合起來是 101.11₂。

    有些小數只會得到近似值

    講義的 0.435：依序乘 2 得到 0.870、1.740、1.480、0.960、1.920、1.840；整數位是 0、1、1、0、1、1。因此保留六位得到 0.011011₂＝0.421875，剩餘小數尚未是 0，所以用 ≈，不能寫成精確相等。

    字元集告訴你有哪些字，編碼形式告訴你如何存成 bits。

    Character set（字元集）列出字元及對應代碼。文字不是以「字的形狀」逐像素儲存，而是用代碼指定字元，再由顯示系統呈現。

    ASCII

    7 bits → 128 種代碼

    American Standard Code for Information Interchange。原始 ASCII 用 7 bits，所以 2⁷＝128；A＝65、a＝97、數字字元「0」＝48。大小寫的代碼不同，文字「0」也不同於數值 0。

    文字壓縮：重複的字串、連續的字、常見的字

    三種方法找的是不同的重複；都要能依規則解回原文。

    方法找什麼？表示方式
    Keyword encoding常見文字片段用保留的特殊符號代替
    Run-length encoding（RLE）連續重複的同一值旗標＋值＋次數

    ① Keyword encoding（關鍵字編碼）

    講義的替代表：as→^、the→~、and→+、that→$、must→&、well→%、these→#。理解用例：the cat and the dog 可寫成 ~ cat + ~ dog，讀取端使用相同替代表解回。

    講義範例 352 字元變成 317 字元：省 35 字元；壓縮率 317/352≈0.90。不適合所有文字：如果沒有那些常見片段，就省不了多少；特殊符號若原本也出現，需要額外的區分或跳脫規則，替代表本身也有成本。

    ② Run-length encoding（遊程長度編碼）

    *n8 表示 n 連續 8 次；* 是 flag（旗標），n 是 value（值），8 是 repetitions（次數）。講義的 *x4*p4c*k7 解回 xxxxppppckkkkkkk。

    bbbbbbbbjjjkaaqqqqqq+++++ → *b8jjjkaa*q6*+5
    25 字元 → 15 字元；壓縮率 15/25＝0.6

    為什麼 j、a 不編碼？jjj 已經只有 3 字元，改成 *j3 仍是 3 字元；aa 若改成 *a2 反而變長。旗標和次數也佔空間，所以短重複不一定值得編碼。

    布林代數：把電路改寫，結果仍然相同

    先辨認 NOT、AND、OR，再用規則化簡；不要套用錯誤的普通算術。

    PropertyAND 形式OR 形式怎麼理解
    Commutative（交換律）AB = BAA + B = B + A交換輸入順序不影響這兩種運算。
    Associative（結合律）(AB)C = A(BC)(A + B) + C = A + (B + C)同一種運算可改分組。
    Distributive（分配律）A(B + C) = AB + ACA + BC = (A + B)(A + C)布林代數也有 OR 對 AND 的分配律。
    Identity（單位律）A·1 = AA + 0 = AAND 的中性元素是 1；OR 的是 0。
    Complement（互補律）AA′ = 0A + A′ = 1A 與反相值不會同時是 1，卻必有一個是 1。
    De Morgan’s law（德摩根定律）(AB)′ = A′ + B′(A + B)′ = A′B′整體取反：AND／OR 互換，每個輸入也取反。

    手算一次 De Morgan

    (AB)′：先 AND，再整體 NOT。它等於 A′ + B′，意思是「A 不是 1，或 B 不是 1」。例如 A = 1、B = 0：左側是 NOT 0 = 1；右側是 0 OR 1 = 1。

    (A + B)′ 則等於 A′B′。例如 A = 1、B = 0：左側 NOT 1 = 0；右側 0 AND 1 = 0。

    最常見陷阱：(AB)′ 不能寫成 A′B′。A = 1、B = 0 就是反例：前者 1，後者 0。括號外的反相作用在整個結果上。

    S-R latch：輸入回到原樣，為什麼還能記住？

    兩個 NAND 閘交叉回授；X 是這張講義採用的儲存狀態。

    把一個閘的輸出接回另一個閘的輸入，形成 feedback（回授），就能讓某種狀態持續存在。講義的 S-R latch 儲存一個 binary digit（1 bit），X = 1 表示存 1，X = 0 表示存 0。

    von Neumann 架構：五個單元分工

    資料與指令邏輯上相同，可以存在同一個地方；「處理」與「儲存」分開。

    講義 p.7 的重點有兩句：Data 與 instructions 在邏輯上相同，可以存在同一個地方（stored-program concept）；process information 與 store information 分開。CPU 負責處理，memory 負責儲存。

    Input unit

    輸入單元

    把外界的資料與程式送進電腦（p.10）。例：鍵盤。

    Output unit

    輸出單元

    把記憶體裡的結果交給外界（p.10）。例：螢幕。

    Memory unit

    記憶單元

    放程式與資料。由許多 cells 組成，每一格有唯一的位址（p.8）。

    ALU

    算術／邏輯單元

    加減乘除，以及 AND、OR、NOT（p.9）。內有速度遠高於記憶體的 registers。

    Control unit

    控制單元

    電腦裡的「組織力量」，負責 fetch-execute cycle（p.11）。

    CPU

    ALU + Control unit

    講義 p.11 的定義：CPU = ALU + control unit。記憶體與輸出入不在 CPU 內。

    記憶體：位址與內容是兩件事（p.8）

    Bus、Cache、Pipelining 與 N-bit 處理器

    Bus 是元件之間的共用通道；後三者都是讓 CPU 更快的設計。

    名詞講義說法一句話記
    Bus（匯流排）每條 bus 傳三種資訊：address、data、control。連接 CPU、記憶體與輸出入的通道。
    Bus width一次可同時傳送的 bits 數。越寬，一次傳得越多。
    Cache memory（快取記憶體）少量高速記憶體，存放常用資料的副本。放常用資料的副本。
    Pipelining（管線化）把一條指令切成較小的步驟，讓步驟彼此重疊，加快 fetch-execute cycle。步驟重疊。
    N-bit processor一條指令就能把兩個 n-bit 數相加；也和位址匯流排、資料匯流排的寬度有關。一次處理 n 位元。

    Fetch-Execute Cycle：CPU 一次一條指令

    四個步驟：Fetch → Decode → Get data → Execute，做完再從頭開始。

    1. Fetch the next instruction：PC 存著下一條指令的位址。指令在記憶體中連續存放，所以下一個 PC = 目前指令的 bytes 數 + 原 PC 的位址（p.15）。
    2. Decode the instruction：控制單元判斷這是哪一種指令，並把它解成 control signals（p.15）。
    3. Get data if needed：有些指令需要額外存取記憶體才能完成（p.16）。
    4. Execute the instruction：送訊號給 ALU 做運算；做完後，循環重新開始（p.16）。
    next PC = 原 PC + 目前指令的 bytes 數
    例：PC = 100，指令長 3 bytes → 下一個 PC = 103

    記憶體與儲存裝置：誰會斷電消失？誰怎麼存取？

    主記憶體多半揮發又有限，所以需要 secondary（auxiliary）storage。

    RAM 與 ROM（p.17）

    類型講義說法揮發性？
    RAM（Random access memory）每個 cell 都可以直接存取。是（volatile）：斷電後內容消失。
    ROM（Read only memory）內容只能讀取，不能改變。否（non-volatile）。

    裝置重點
    Magnetic tape（磁帶，p.19）第一個真正的大量輔助儲存裝置。缺點：要讀中段資料，前面的資料都得先存取再丟掉（循序存取）。
    Magnetic disk（磁碟，p.20–21）Tracks（磁軌）是同心圓；每個 track 分成 sectors（磁區）；每個 sector 放一個 block（區塊）。圖中另標示 cylinder（磁柱），指多片碟片上相同位置的 tracks 疊起來的集合。

    平行架構：四個層級與三種硬體

    Bit → Instruction → Data → Task：從一次處理的位元，到不同處理器做不同任務。

    層級講義說法關鍵字
    Bit-level（位元級）增加電腦的 word size。字長變大
    Instruction-level（指令級）程式中有些指令可以彼此獨立、同時進行。Superscalar（超純量）：多個 execution units
    Data-level（資料級）同一組指令，同時作用在不同的資料集上。SIMD、synchronous processing
    Task-level（任務級）不同的處理器，在相同或不同的資料集上執行不同的任務。MIMD、pipelined processing

    Shared-memory parallel processor（p.31）

    屬於 task-level 的 MIMD；多個 processors 透過shared memory 溝通，每個 processor 另有自己的 local memory。

    平行硬體（p.32）

    硬體講義說法
    Multicore processors（多核心處理器）多個獨立的 cores；把多條指令送給多個 execution units。
    Symmetric multi-processors（SMPs，對稱多處理器）多個相同的 cores；共用記憶體，並由 bus 連接。
    Massively parallel processors（大規模平行處理器）講義只列出名稱。
    講義歸類提醒：p.30 把 pipelined processing 放在 task-level；p.13 的 pipelining 則是把單一指令切成可重疊的步驟。考試以講義的歸類為準。第一章也出現 SIMD／MIMD，可回到第一章的平行運算對照。

    先讀：這些題型要怎麼做？

    整數／小數換算

    整數用位置權重或反覆除；小數換成 base b 時反覆乘 b，整數位按產生順序讀。例：0.6875×16=11=B，所以 0.6875₁₀=0.B₁₆。directly 問直接法，2↔16 用每 4 bits 對應；計算機核對不取代題目要求的過程。

    固定 10-bit 補數

    範圍 −512–511。負數固定 10 位反轉加 1；減法 A−B 改成 A+(−B)。先看數學答案是否超出範圍，再看保留的 10-bit 圖樣。例如 400+200=600 超出上限，低 10 位 1001011000 解讀為 −424；−424 是溢位後的儲存解讀，不能當作數學答案。

    Huffman 要自己建樹

    每輪重新取最小權重兩個節點合併；本區規定小權重在左，同權重用排序後的組名字母比較。左 0、右 1，從根到葉讀碼，解碼每到葉就回根。建樹題要填全部合併步驟與七個碼字，不只認識「常見字用短碼」。

    指定有效位數的浮點數

    本區採 sign × 整數 mantissa × 10^exponent。有效位數不是小數點後幾位。例：12.346，4 位尾數採截取是 +×1234×10⁻²，採四捨五入是 +×1235×10⁻²。原作業題幹未明說捨入，但實習課 p.59 解答採截取；本區的自編題仍各自明示截取或四捨五入。

    RLE 保留符號與大小寫

    本區只有長度大於 3 的連續重複改成 *字元次數；短段保留。#、@、+ 都可當資料字元，* 才是旗標。例：@@@@zz → *@4zz。文字編解碼須保持字元順序。

    自我測驗

    先在腦中回答，再點開答案。能解釋原因才算真的會。

    1. SIMD 的完整名稱是什麼？它和 MIMD 最大差在哪裡？
    SIMD = Single Instruction, Multiple Data；MIMD = Multiple Instruction, Multiple Data。前者讓多筆資料執行同一指令，後者可同時執行不同指令處理不同資料。
    2. Jacquard、Babbage、Ada Lovelace、Turing 各對應什麼？
    Jacquard → punched card；Babbage → Analytical Engine；Ada Lovelace → first programmer / loop；Alan Turing → Turing machine。
    3. 硬體世代從第一代到第四代的關鍵元件？
    Vacuum Tube → Transistor → Integrated Circuit → LSI/VLSI。
    4. 為什麼 (30B)₁₆ = 779₁₀？
    因為 B 代表 11，所以 3×16² + 0×16¹ + 11×16⁰ = 768 + 11 = 779。
    5. Binary 要轉 Hex，為什麼是 4 bits 一組？
    因為 16 = 2⁴，所以一個十六進位數字可以剛好表示 4 個 binary bits 的 16 種組合。
    6. 150₁₀ 用 Binary、Octal、Hex 表示？
    150₁₀ = 10010110₂ = 226₈ = 96₁₆。
    7. 1 Byte、Half Word、Full Word、Double Word 各是多少 bits？
    Byte = 8；Half Word = 16；Full Word = 32；Double Word = 64 bits。
    8. Binary subtraction 遇到 0 − 1 怎麼辦？
    向左邊借 1。因為二進位的一個借位在目前欄等於 10₂，所以 10₂ − 1₂ = 1₂。這就是教材標示的 borrow。
    9. 第一章第5頁的六層架構，由內到外的順序是什麼？
    Information → Hardware → Programming → Operating systems → Applications → Communications。先辨認資訊、實體設備、程式設計、系統管理、使用者應用、系統間通訊各在做什麼。
    10. 第二代硬體的三組「取代關係」是什麼？
    Transistor 取代 Vacuum Tube；Magnetic Cores 取代 Magnetic Drums；Magnetic Disks 取代 Magnetic Tape。分別是在講代表元件、記憶體、輔助儲存，三組要分開記。
    11. Assembler、Compiler、Linker、Loader、OS 各負責什麼？
    Assembler：組合語言翻成機器語言；Compiler：高階語言翻成機器指令（依講義）；Linker：連結程式片段；Loader：載入程式到記憶體；OS：管理資源並安排工作。抓住翻譯、連結、載入、排程四種工作。
    12. 講義的 Moore’s Law 為什麼有「每年」與「18個月」兩個數字？
    第11頁介紹早期版本，描述單一IC可容納的電路數量每年加倍；第12頁列修訂版本，描述晶片密度每18個月加倍。看題目指定的版本來回答。
    13. 計算平均成績時，如何使用最後一頁的四項能力？
    Algorithmic thinking：想出逐筆加總再除以人數的步驟；Representation：決定如何表示名字與成績；Programming：把步驟寫成程式；Design：安排輸入、檢查、計算、呈現結果的整體流程。它們共同支援有效率地自動化。
    14. 同一個 10000010，無號整數與二補數各是多少？
    無號值 130；8-bit 二補數因最高位是 1，所以 130−256＝−126。表示規則決定解讀方式。
    15. 為什麼補數要先固定位數？
    負 I 的 k-bit 圖樣對應 2ᵏ−I；改變 k 就改變表示法。−2 的 8-bit 是 11111110，不能任意省去前面的 1。
    16. 0.435≈0.011011₂，為什麼是近似？
    乘 2 取到六個 bits 後仍有剩餘小數；0.011011₂＝0.421875，所以不是精確相等。
    17. 壓縮率 0.39，是省下 39% 嗎？
    依講義定義，壓縮後約為原來的 39%；省下約 61%。公式與單位要先看清楚。
    18. Huffman 碼為什麼不能固定每 4 bits 分組？
    它是變長編碼。需使用同一張碼表，按完整碼解出字元；無前綴歧義可使解碼明確。
    19. 取樣更多與量化 bits 更多，分別改變什麼？
    前者增加時間上量測的密度；後者增加可用振幅等級（2ᵇ）。兩者也會影響未壓縮樣本資料量。
    20. 影片的 Temporal 與 Spatial 差在哪？
    Temporal 比較連續影格與變化，包含 keyframe／delta 的概念；Spatial 在同一張影格內減少冗餘。

    De Morgan 要把 AND 改成 OR，所以 (AB)′=A′+B′。用 A=1、B=0 作反例，(AB)′=1，但 A′B′=0。
