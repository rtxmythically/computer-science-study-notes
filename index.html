Chapter 01 · 01 · PDF p.3–5

Computing System：零件怎麼一起完成工作？

先分清硬體與軟體，再用六層架構看它們如何合作。

講義把 computing system 定義成一個 dynamic entity（動態實體）：它接收環境中的資訊、處理問題，並與環境互動。例如你按下鍵盤，系統處理輸入，畫面顯示文字；這一連串行為就是系統正在運作。

Hardware · 實體元件

電腦「用什麼」執行工作

Hardware 是實體元件。講義例子有 printer（印表機）、circuit boards（電路板）、wires（線路）、keyboard（鍵盤）。它們能接收、傳送或處理實際的訊號。

辨認方法：看這個名詞指的是設備或元件，還是提供指令的程式。

Software · 程式與指令

電腦「按照什麼規則」工作

Software 是提供 instructions（指令）的 programs（程式）。例如「把輸入的文字顯示出來」這個行為，需要軟體告訴硬體要怎麼做。

理解用例：手機的螢幕是硬體；執行中的聊天程式是軟體。作業系統也是軟體。

兩者的關係：軟體提供做事的規則，硬體執行這些規則。辨認時看名詞的角色：下載的程式屬於軟體，承載它的儲存設備屬於硬體。

歷史：從記錄數值，到描述計算步驟

把每個人物連到一項貢獻，再理解這項貢獻讓什麼變得可能。

這段歷史可以沿著一條線理解：記錄數值 → 機械運算 → 用編碼控制動作 → 設計計算機 → 撰寫計算步驟 → 研究計算的理論。這樣遇到人物配對題，就能從他的工作找答案。

Abacus（算盤）→ 記錄數值講義將算盤列為早期記錄 numeric values 的裝置。重點是用可操作的形式表示數值。
Blaise Pascal → 機械式加減早期機械裝置能做 addition、subtraction；講義接著指出後來的裝置擴展到乘法與除法。看到 Pascal，要想到 mechanical calculation。
Joseph Jacquard → 織布機與 Punched card打孔卡用來控制織布機。理解重點：把要做的動作編成可讀取的形式，機器就能照編碼操作。
Charles Babbage → Analytical Engine（分析引擎）講義將分析引擎與 Babbage 配對。記住他主要對應的是計算機的設計。
Ada Lovelace → First programmer／Loop講義稱她為第一位程式設計師，並列出迴圈概念。Loop 是讓相同的一組步驟重複執行，重點在描述「怎麼算」。
Alan Turing → Turing machine（圖靈機）講義強調圖靈機奠定計算理論的重要基礎。看到 Turing，要想到對計算本身的理論研究。

容易混淆：Babbage vs Ada

Babbage＝機器設計；Ada＝程式與迴圈。兩人都與分析引擎的脈絡有關，但配對時要看題目在問機器，還是程式設計。

早期電腦名稱

Harvard Mark I、ENIAC、UNIVAC I 都是講義列出的早期電腦。講義指出它們開啟數學、物理、工程與經濟等領域的新應用。

Fortran／COBOL／Lisp 是語言；Mosaic／Netscape 是瀏覽器。先判斷名稱是哪一類，選項就容易排除。

配對口訣：算盤＝數值；Pascal＝加減；Jacquard＝打孔卡；Babbage＝分析引擎；Ada＝程式／迴圈；Turing＝圖靈機。

Sequential vs Direct access

Sequential（循序）像從前面依序讀資料；Direct（直接）能定位要取出的資料。講義用磁帶與磁碟來比較兩者。

理解用例

像要找第六筆紀錄：循序方式一路讀過前面的紀錄；直接方式可指定要找的紀錄。這個比喻用來理解「存取方式」。

CISC vs RISC

CISC＝Complex-instruction-set computer（複雜指令集）。RISC＝Reduced-instruction-set computer（精簡指令集）。

先抓 Complex／Reduced 這兩個英文詞。它們是在分指令集設計；看到名詞，先回答它代表哪種設計。

Portable computer 的講義例子有 notebook、laptop、tablet computer、smart phone。

Parallel Computing：分工的是指令，還是資料？

把縮寫拆成 Instruction 與 Data，再看實際的分工。

講義的平行計算是利用相互連接的處理單元或記憶單元增加處理速度。理解 SIMD／MIMD 時，先問兩件事：「大家收到同一種指令嗎？」以及「大家處理的是多份資料嗎？」

SIMD

Single Instruction, Multiple Data Stream

SI＝單一指令；MD＝多筆資料。多個處理單元使用相同指令，分別作用在不同資料上。

理解用例

四個人分別拿到 2、4、6、8；所有人都接到「加 1」的指令。工作相同，資料不同。

MIMD

Multiple Instruction, Multiple Data Stream

MI＝多種指令；MD＝多筆資料。不同處理單元可以執行不同指令，處理不同資料。

理解用例

四個人分別接到「加 1、乘 2、減 1、平方」的工作；各自處理自己的資料。

縮寫讀法：先看前半段 SI／MI，決定指令是同一種還是多種。兩者的 MD 都表示 Multiple Data；差異就在 Instruction。

Internet 與 World Wide Web 的關係

Internet 是互連的網路；World Wide Web（WWW）是透過 Internet 使用的網頁服務。講義第 20 頁將 WWW 和 browser 放在第五代軟體的脈絡中。

Cloud 的關鍵：資源在哪裡？

本機計算使用你所在裝置的資源；雲端運算透過 Internet 使用遠端資源。

理解用例

同樣是處理資料，可以由自己電腦的 CPU 執行，也可以交給遠端服務執行，再透過網路取回結果。

軟體五世代：從指令到應用與系統管理

軟體世代看語言、管理方式與應用的發展；先分清各工具在做哪一件事。

早期程式直接用 0、1 表示指令，後來改用助記碼與較接近英文的高階語言；系統軟體再負責連結、載入、排程，讓應用程式更容易被使用。語言的表示方式、程式翻譯、系統管理是三個不同的角色。

Machine Language → Assembly → High-Level Language

機器語言

直接用 binary（1s and 0s）表示指令。早期程式設計師必須記住不同位元組合代表的操作。

組合語言

用 mnemonic codes（助記碼）代表機器指令，較容易辨認操作；再由 Assembler 翻譯。

高階語言

用較接近英文或人類想法的敘述寫程式；依講義，由 Compiler 翻成機器指令。

避免混淆：Assembler／Compiler 負責翻譯；Linker 負責連結；Loader 負責載入；OS 負責管理資源與安排工作。看到題目先辨認動詞。

第四、第五代：看懂這些應用名詞

Structured Programming（結構化程式設計）

講義強調 logical and disciplined：用有邏輯、有組織的方式寫程式。語言例子包含 Pascal、BASIC、C、C++。

這裡的 Pascal 是語言名稱；前面 Blaise Pascal 是歷史人物。看題目的脈絡再判斷。

Application Software（應用軟體）

Spreadsheets：試算表，例 Lotus 1-2-3。Word processors：文書處理，例 WordPerfect。Database management systems：資料庫管理，例 dBase。

它們提供使用者完成具體任務的功能。

Object-Oriented Design（物件導向設計）

講義以資料物件的階層來描述設計，並列 C++、Java 為例。理解時，可以想成將相關資料與行為組織在物件中。

C++ 在講義第四、第五代都出現；辨認世代時，看主題是在說結構化程式設計，還是物件導向。

WWW 與 Embedded System

WWW 透過 Internet 支援全球溝通，Browser 的講義例子有 Mosaic、Netscape、IE、Firefox。

Embedded System（嵌入式系統）把晶片整合到設備中，執行或控制功能。理解用例：設備內的控制晶片依設定調節運作。

Computer as a Tool and a Discipline

把「使用電腦做事」與「研究如何有效率地自動化」連起來。

電腦可以是工具，幫其他領域解決問題；計算機科學也是一個學科，研究如何表示問題、設計步驟、寫成程式，並有效率地自動化。講義最後的根本問題是：What can be efficiently automated?

Algorithmic thinking

演算思考：把問題拆成可執行步驟

先想清楚輸入、要做哪些操作、完成條件和輸出。

理解用例 · 計算平均成績

    Number Systems & Positional Notation

    進位真正的核心只有一件事：每個位置都有不同的 base 次方權重。

    Common Bases

    常見進位

    • Binary：base 2 → 0, 1
    • Octal：base 8 → 0–7
    • Decimal：base 10 → 0–9
    • Hexadecimal：base 16 → 0–9, A–F
    Number Sets

    數字集合

    Chapter 02 · 02

    進位轉換：三個方法

    不同方向用不同方法，會比硬背所有表格簡單很多。

    To Decimal

    其他進位 → 10 進位

    使用位置權重：每位數 × base 的次方後相加。

    From Decimal

    10 進位 → 其他進位

    整數常用「反覆除以 base，記錄餘數，再由下往上讀」。

    Shortcut

    2 ↔ 8 / 16

    Octal 每 1 位對應 3 bits；Hex 每 1 位對應 4 bits。

    考試怎麼算：先判斷是哪一種題型

    先記這三句： 看到「→ Decimal」就乘次方； 看到「Decimal →」就一直除、餘數倒著讀； 看到 Binary ↔ Octal / Hex，就直接每 3 bits / 4 bits 分組。
    Type 1 · To Decimal

    ① 其他進位 → 10 進位：乘權重再相加

    例：(30B)₁₆ → (?)₁₀

    16 進位中 A=10、B=11、C=12、D=13、E=14、F=15。

    從最右邊開始，位數權重依序是 16⁰、16¹、16²⋯。

    (30B)₁₆ = 3×16² + 0×16¹ + 11×16⁰
    = 3×256 + 0 + 11 = 779

    答案： (30B)₁₆ = (779)₁₀

    其實和十進位 352 = 3×10² + 5×10¹ + 2×10⁰ 是同一個概念，只是把 base 換成 16。

    Type 2 · From Decimal

    ② 10 進位 → 其他進位：一直除，餘數倒著讀

    例：(2748)₁₀ → (?)₁₆

    計算商餘數
    2748 ÷ 1617112 = C
    171 ÷ 161011 = B
    10 ÷ 16010 = A

    餘數一定要由下往上讀：A → B → C。

    (2748)₁₀ = (ABC)₁₆

    最常錯：把餘數由上往下讀成 CBA。

    Type 3 · Binary Shortcut

    ③ Binary ↔ Octal / Hex：直接分組

    因為 8 = 2³，所以 Binary ↔ Octal 每 3 bits 一組；16 = 2⁴，所以 Binary ↔ Hex 每 4 bits 一組。

    Binary → Hex

    例：(10010110)₂

    1001  0110 → 9  6

    所以 (10010110)₂ = (96)₁₆。

    Binary → Octal

    從右邊每 3 bits 分組，不足時在左邊補 0。

    10010110 → 010  010  110 → 2  2  6

    所以 (10010110)₂ = (226)₈。

    反過來 Octal / Hex → Binary： 每一個 Octal digit 各換成 3 bits；每一個 Hex digit 各換成 4 bits，再把各組接起來。 例如 (226)₈ → 010 010 110 → (10010110)₂；最左邊不影響數值的 0 可以省略。
    同一個值的完整對照： (150)₁₀ = (10010110)₂ = (226)₈ = (96)₁₆。 考試時先看「從哪一進位轉去哪一進位」，再選方法，不要全部都用同一套算法。

    課本例題

    (2748)₁₀ → Hex

    (2748)₁₀ = (ABC)₁₆

    同一個值的不同表示

    (150)₁₀ = (10010110)₂ = (226)₈ = (96)₁₆
    超重要： Binary ↔ Octal：每 3 bits 分一組。Binary ↔ Hex：每 4 bits 分一組。
    Chapter 02 · 03

    Binary Arithmetic

    二進位加法規則少，但進位的位置很容易粗心。

    運算結果說明
    0 + 00不進位
    0 + 1 / 1 + 01不進位
    1 + 110₂寫 0，進 1
    1 + 1 + 111₂寫 1，進 1

    教材例題：二進位直式相加

    和十進位直式加法一樣，從最右邊開始，只是二進位逢 2 就進位。

    1010111 + 1001011 --------- 10100010

    第一步：最右邊 1 + 1 = 10₂，所以這一欄寫 0，往左進 1。

    第二步：下一欄要把進位一起加：1 + 1 + 1 = 11₂，所以寫 1，再進 1。

    後面每一欄都照同樣規則往左算，最後得到 (10100010)₂。

    考試做法：從右往左一欄一欄加；遇到 1 + 1 就「寫 0 進 1」，遇到 1 + 1 + 1 就「寫 1 進 1」。建議把進位標在上一列，比較不容易漏掉。

    Binary Subtraction（二進位減法）

    先懂「借 1」是什麼： 十進位向左借 1，這一欄會多 10；二進位向左借 1，這一欄會多 2，也就是 10₂。 所以遇到 0 − 1 時，可以變成 10₂ − 1₂ = 1₂。
    Step 1 · Rules

    先記 4 個基本情況

    運算結果要不要借位
    0 − 00不用
    1 − 01不用
    1 − 10不用
    0 − 11要：先變成 10₂ − 1₂
    Step 2 · Simple Borrow

    最簡單借位：10₂ − 1₂

    10 - 01 ---- 01

    最右邊是 0 − 1，不夠減，所以向左邊的 1 借 1。

    左邊的 1 變成 0；右邊的 0 得到 10₂，所以 10₂ − 1₂ = 1₂。

    連續借位：中間遇到 0 怎麼辦？

    例如 1000₂ − 0001₂。最右邊 0 − 1 不夠，但左邊緊鄰的兩欄也都是 0，所以要一路往左找到第一個 1。

    1000 - 0001 ------ 0111

    最左邊的 1 借出去後變 0；借位一路傳過兩個 0，最後右邊三欄都能完成減法，所以 (1000)₂ − (1)₂ = (111)₂。

    教材例題：逐欄看 borrow

    1010111 - 0111011 --------- 0011100

    從最右邊開始：

    1. 第 1 欄：1 − 1 = 0。
    2. 第 2 欄：1 − 1 = 0。
    3. 第 3 欄：1 − 0 = 1。
    4. 第 4 欄：0 − 1 不夠，向左借 1 → 10₂ − 1₂ = 1。
    5. 第 5 欄：因為剛剛被借走，這欄變成 0；現在又是 0 − 1，所以要再向左借。
    6. 左邊下一欄也是 0，因此借位要再往左找到 1，再把 borrow 傳回來。
    7. 剩下各欄完成相減後，結果是 0011100₂。
    考試口訣：從右往左減；夠減就直接減，不夠減就向左借 1。如果左邊是 0，就繼續往左找到第一個 1。Addition 看 carry；Subtraction 看 borrow。

    Self Test

    自我測驗

    先在腦中回答，再點開答案。能解釋原因才算真的會。

    1. SIMD 的完整名稱是什麼？它和 MIMD 最大差在哪裡？
    SIMD = Single Instruction, Multiple Data；MIMD = Multiple Instruction, Multiple Data。前者讓多筆資料執行同一指令，後者可同時執行不同指令處理不同資料。
    2. Jacquard、Babbage、Ada Lovelace、Turing 各對應什麼？
    Jacquard → punched card；Babbage → Analytical Engine；Ada Lovelace → first programmer / loop；Alan Turing → Turing machine。
    3. 硬體世代從第一代到第四代的關鍵元件？
    Vacuum Tube → Transistor → Integrated Circuit → LSI/VLSI。
    4. 為什麼 (30B)₁₆ = 779₁₀？
    因為 B 代表 11，所以 3×16² + 0×16¹ + 11×16⁰ = 768 + 11 = 779。
    5. Binary 要轉 Hex，為什麼是 4 bits 一組？
    因為 16 = 2⁴，所以一個十六進位數字可以剛好表示 4 個 binary bits 的 16 種組合。
    6. 150₁₀ 用 Binary、Octal、Hex 表示？
    150₁₀ = 10010110₂ = 226₈ = 96₁₆。
    7. 1 Byte、Half Word、Full Word、Double Word 各是多少 bits？
    Byte = 8；Half Word = 16；Full Word = 32；Double Word = 64 bits。
    8. Binary subtraction 遇到 0 − 1 怎麼辦？
    向左邊借 1。因為二進位的一個借位在目前欄等於 10₂，所以 10₂ − 1₂ = 1₂。這就是教材標示的 borrow。
    9. 第一章第5頁的六層架構，由內到外的順序是什麼？
    Information → Hardware → Programming → Operating systems → Applications → Communications。先辨認資訊、實體設備、程式設計、系統管理、使用者應用、系統間通訊各在做什麼。
    10. 第二代硬體的三組「取代關係」是什麼？
    Transistor 取代 Vacuum Tube；Magnetic Cores 取代 Magnetic Drums；Magnetic Disks 取代 Magnetic Tape。分別是在講代表元件、記憶體、輔助儲存，三組要分開記。
    11. Assembler、Compiler、Linker、Loader、OS 各負責什麼？
    Assembler：組合語言翻成機器語言；Compiler：高階語言翻成機器指令（依講義）；Linker：連結程式片段；Loader：載入程式到記憶體；OS：管理資源並安排工作。抓住翻譯、連結、載入、排程四種工作。
    12. 講義的 Moore’s Law 為什麼有「每年」與「18個月」兩個數字？
    第11頁介紹早期版本，描述單一IC可容納的電路數量每年加倍；第12頁列修訂版本，描述晶片密度每18個月加倍。看題目指定的版本來回答。
    13. 計算平均成績時，如何使用最後一頁的四項能力？
    Algorithmic thinking：想出逐筆加總再除以人數的步驟；Representation：決定如何表示名字與成績；Programming：把步驟寫成程式；Design：安排輸入、檢查、計算、呈現結果的整體流程。它們共同支援有效率地自動化。
